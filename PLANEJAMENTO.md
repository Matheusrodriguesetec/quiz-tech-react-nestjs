PLANEJAMENTO DO PROJETO – QUIZ TECH
1. Nome do projeto
Quiz Tech – TypeScript, React e NestJS.

2. Objetivo
Desenvolver uma aplicação web de perguntas e respostas para avaliar os conhecimentos dos usuários sobre TypeScript, React e NestJS.

3. Descrição
O projeto consiste no desenvolvimento de um quiz interativo em uma página web HTML, utilizando JavaScript e React para a construção da interface e implementação das funcionalidades.A
O quiz contará com 20 questões, cada uma contendo cinco alternativas e apenas uma resposta correta.

4. Tecnologias utilizadas
HTML5: estrutura da página.
CSS3: estilização e organização visual.
JavaScript: lógica da aplicação.
React: construção dos componentes e interface interativa.
NestJS: tecnologia estudada para compreender a estrutura de aplicações backend.
GitHub: armazenamento e compartilhamento do projeto.

5. Funcionalidades
Tela inicial com botão para começar.
Exibição de 20 perguntas.
Cinco alternativas por pergunta.
Seleção de apenas uma resposta.
Verificação automática das respostas.
Contagem de pontos.
Exibição do resultado final.
Indicação de aprovação ou reprovação.

6. Critério de avaliação
Cada questão valerá um ponto, totalizando 20 pontos. 
Para aprovação, será necessário alcançar pelo menos 12 pontos (60%).

7. Etapas de desenvolvimento
Planejamento da aplicação.
Pesquisa sobre React e NestJS.
Desenvolvimento da interface.
Cadastro das 20 questões.
Implementação da lógica de respostas.
Implementação do sistema de pontuação.
Desenvolvimento da tela de resultados.
Testes e correções.
